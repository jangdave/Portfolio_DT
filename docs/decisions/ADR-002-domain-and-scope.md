# ADR-002: 도메인은 가상 데이터센터, 범위는 소형 고정

- 상태: 채택
- 날짜: 2026-10-15

## 결정
도메인은 **가상 데이터센터 1개 홀**. 랙 20기 이내, CRAC 2~4기, 시나리오 4종(normal, cooling_failure, power_spike, fan_fault).

## 근거
- 랙/냉각 장치의 반복 구조라 직접 모델링(Blender)과 모듈화가 쉽다.
- 열/기류 시각화(베이크)와 센서 알람(실시간)이 한 시나리오에 자연스럽게 들어간다.
- 재직 회사의 도메인(에너지/플랜트)과 겹치지 않아 기밀 이슈를 줄이고, 센서·알람·시각화 경험은 그대로 보여줄 수 있다.

## 대안
스마트 팩토리(AGV, 로봇 팔). → 확장 후보로 보류.

## 한계
실제 CFD 정확도를 주장하지 않는다(시각화 목적).
