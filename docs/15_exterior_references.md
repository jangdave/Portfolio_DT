# 15. 건물 외관 레퍼런스 조사

- 상태: 초안 (2026-10-15)
- 목적: 대형 데이터센터 외관에서 **공통으로 보이는 특징**을 조사하고, 우리 가상 건물 모델(`usd/assets/building.usda`)에 무엇을 반영했는지 남긴다.
- 쓰는 방법: 이 문서는 "공통 특징을 배우는 용도"이다. **특정 시설의 형상, 도면, 로고, 상표, 간판 문구를 따라 하지 않았다.** 사진은 저장소에 저장하지 않았다.
- 관련 문서: [09 USD 규격](09_usd_spec.md) 12장, [ADR-008](decisions/ADR-008-screen-flow-exterior-to-floor.md), [회사 자산 분리 규칙](04_clean_room_policy.md)
- 확인 방법과 한계: 2026-10-15에 웹 검색을 하고 **검색 결과에 나온 요약과 제목**으로 내용을 확인했다. 아래 출처의 원문 전체를 모두 열어 읽지는 않았다. 계획 문서(도면, 허가 서류)와 제품 소개(제조사 설명)가 섞여 있어서, 한 곳에서만 확인된 내용은 "사례"로만 적고 일반 규칙처럼 쓰지 않았다.

## 2. 공통 특징 정리

| 항목 | 공통으로 확인된 내용 (출처 번호) | 한 곳에서만 확인한 사례 |
|---|---|---|
| 건물 형태 | 창이 거의 없는 저층 대형 직육면체, 패널로 모듈식 확장 (2, 15, 16) | 다층 건물 + 층마다 공조 (1) |
| 외벽 재료와 분할 | 단열 금속 패널, 프리캐스트 콘크리트, 회색 계열, 패널 분할선이 그대로 보임 (1, 2, 4, 7, 8, 9) | 벽돌, 넓은 유리면으로 변화 (2) |
| 환기 루버, 외기 흡입구 | 외벽 일부를 루버로 만들고 공기 흐름과 비 막기를 함께 함 (4, 5, 10, 12) | 구멍 뚫린 패널로 열 배출 (9) |
| 옥상 설비 | 냉각기(칠러)를 옥상에 올림, 가림벽으로 둘러쌈 (1, 4, 12) | - |
| 옥외 설비 | 발전기 줄, 지상 연료 탱크, 변전 구역, 냉각탑 (1, 13, 14) | 발전기 2단 쌓기 (1) |
| 보안 울타리와 출입구 | 높이 약 2.4 m 창살형 울타리, 경비실, 카드키 (10, 11, 7) | - |
| 주차와 조경 | 입구 쪽만 가로수와 화단으로 부드럽게, 설비는 가림 (3, 7) | - |
| 외관 질감 | 금속 패널의 **이음선**, 칠한 금속의 단순한 색. 오염과 빗물 자국은 출처에서 직접 확인하지 못했고 **일반 건축 상식에 따라 약하게** 넣었다. | - |

## 3. 우리 모델에 반영한 점

| 특징 | 반영 (파일: `blender/scripts/make_building_exterior.py`) | 근거 번호 |
|---|---|---|
| 저층 대형 직육면체 | 72 x 45.6 m, 3층 x 4.8 m. 홀(11.0 x 13.6 x 4.0 m)이 3층에 들어가는 크기. 이 치수는 **직접 정한 값**이다. | 2, 15, 16 |
| 모듈형 패널 | 1.2 x 2.4 m 패널을 하나씩 모델링(틈 2 cm), 층 경계 알루미늄 띠. 패널 텍스처에도 같은 이음선 | 1, 4, 7, 8 |
| 환기 루버 | 서쪽, 동쪽, 뒤쪽 벽에 루버 묶음 42개(테두리, 어두운 뒷판, 기울어진 슬랫) | 4, 5, 10, 12 |
| 옥상 설비 | 냉각기 20대(팬 3개씩, 팬 날개 6장과 보호망 고리), 배기관 8개, 계단실/설비실, 배관, **루버 가림벽** | 1, 4, 12 |
| 냉각탑 | 4기(수조, 본체, 흡입 루버, 팬 굴뚝, 사다리), 냉각수 배관 | 13 |
| 발전기 | 컨테이너형 8대(연료 받침, 흡기 루버, 배기관), 지상 연료 탱크 2기 | 1, 13, 14 |
| 변전 설비 | 변압기 4기(방열 핀, 고압 연결부 애자), 문형 철골, 바닥판. 건물 뒤쪽에 둠 | 13, 14 |
| 보안 울타리와 출입구 | 높이 2.4 m 창살형 울타리(기둥 3 m 간격), 미닫이 정문, 경비실, 차단기 | 10, 11 |
| 주차와 조경 | 주차선, 조명 기둥, 입구 앞 산울타리와 가로수(단순한 모양) | 3, 7 |
| 외관 질감 | 패널 이음 홈과 나사, 위 이음선에서 흘러내린 가는 오염 줄, 콘크리트 줄눈, 아스팔트 알갱이와 금, 지붕 방수막 이음 (텍스처는 모두 직접 생성) | 7, 9, 상식 |

## 4. 반영하지 않은 것

- 특정 사업자의 외관 색, 로고, 간판 문구, 건물 이름. 건물 이름(`dct:title`)은 중립적인 문구(`Data Center Building`)이다.
- 창이 있는 사무동, 넓은 유리 정면, 벽돌, 구멍 뚫린 패널. 범위를 줄이기 위해 뺐다. 필요하면 재질 칸을 늘려 추가한다.
- 발전기 2단 쌓기, 지하 연료 탱크, 건물 확장 칸. (한 가지 모양만 만들었다.)
