# 16. 서버 홀 내부 레퍼런스 조사

- 상태: 초안 (2026-10-15)
- 목적: 대형 데이터센터 서버 홀 **내부**에서 공통으로 보이는 특징을 조사하고, 우리 가상 홀 모델에 무엇을 넣을지 정한다. 모델링 담당이 이 문서를 보고 만든다.
- 쓰는 방법: "공통 특징을 배우는 용도"이다. **특정 제품의 형상, 로고, 라벨 문구를 따라 하지 않는다.** 사진은 저장소에 저장하지 않았다.
- 관련 문서: [15 건물 외관 레퍼런스](15_exterior_references.md), [09 USD 규격](09_usd_spec.md), [회사 자산 분리 규칙](04_clean_room_policy.md)
- 확인 방법과 한계: 2026-10-15에 웹 검색을 하고 **검색 결과에 나온 요약과 제목**으로 내용을 확인했다. 출처 원문 전체를 모두 열어 읽지는 않았다. 제조사 소개와 업체 블로그가 많아서, 숫자는 "업체가 말하는 값"일 수 있다. 표의 "확인"은 위 방식으로 본 내용이고, "추정"은 근거를 찾지 못해 우리가 정한 값이다.

## 2. 항목별 조사와 우리 모델 반영

### 2.1 이중 바닥

| 확인한 특징 (출처) | 확인 / 추정 | 우리 모델에 이렇게 만든다 |
|---|---|---|
| 타일은 600 x 600 mm가 세계 공통 규격이고, 옛 24 x 24인치와 거의 같다 (S1, S2, S5) | 확인 | 타일 60 x 60 cm 격자. 이음 틈은 0.2 cm 정도로 얇게 모델링한다. |
| 공조기가 만든 찬 공기를 바닥 아래로 보내고, 천공 또는 격자 타일로 랙 앞에 올려 보낸다 (S1, S2, S3) | 확인 | 천공 타일은 차가운 통로 쪽에만 둔다. 급기구는 50 x 100 cm(타일 2장)로 정했으므로 타일 2장을 이어 붙인 모양으로 만든다. |
| 천공 타일의 열린 면적은 흔히 25%, 고개방 격자 타일은 약 56%라고 업체가 말한다 (S3, S4) | 확인 (업체 주장) | 구멍 면적은 25% 정도로 보이는 천공 무늬. 구멍을 하나하나 모델링하지 않고 알파 텍스처나 노멀 맵으로 표현한다(삼각형 수 절약). |
| 바닥 아래 높이는 자료마다 다르다. 최소 약 450 mm, 600~900 mm가 흔하고 고밀도 홀은 1200 mm까지 간다 (S1, S2). 받침대 조절 범위는 150~1200 mm (S1) | 확인 (2차 자료) | 홀 안쪽 높이 4.0 m에 이중 바닥 높이가 포함되는지는 모델링 담당이 정한다. 제안은 바닥 위 약 60 cm, 바닥 단면(컷어웨이)에서 받침대 기둥과 아래 공간이 보이게 한다. 이 높이는 **우리가 정한 값**이다. |
| 타일 위 하중 기준은 약 1465 kg/m2 (S1) | 확인 | 모델에는 반영하지 않는다(보이지 않는 값). |
| 타일 색, 표면 질감 | 확인하지 못함 | 추정: 밝은 회색 단색 + 약한 거칠기. 타일 가장자리는 어두운 회색 테두리 띠. |

### 2.2 벽과 천장 마감

| 확인한 특징 (출처) | 확인 / 추정 | 우리 모델에 이렇게 만든다 |
|---|---|---|
| 벽, 바닥, 천장을 흰색으로 칠하는 경우가 많고, 사진에서는 장비에 시선이 쏠려 흰 면은 배경처럼 보인다 (S15) | 확인 (에세이) | 벽은 밝은 흰색에 가까운 회색(반사율 약 0.8). 순백은 피한다. |
| 천장은 금속 틀(주 레일, 가로 레일, 매다는 봉)로 만든 격자형이고, 케이블과 격벽을 매달 만큼 단단하다 (S16) | 확인 | 천장 격자 60 x 60 cm. 이중 바닥 타일과 같은 격자에 맞춘다. 격자선은 얇은 홈으로 보이게 한다. |
| 데이터센터용 천장 격자는 흰색 제품이 있다 (S17) | 확인 | 천장 타일은 흰색, 레일은 흰색 또는 밝은 회색. |
| 천장 위 공간을 공기가 돌아오는 길(플레넘)로 쓰는 경우가 있다 (S16, 공조기 자료 S11 관련) | 확인 | 이번 모델에서는 천장 위를 만들지 않고 천장 면만 만든다. 회수 격자는 천장 타일 몇 장을 격자 타일로 바꿔 표현할 수 있다(선택). |
| 에폭시 바닥, 벽 하단 보호 띠 등 마감 일정표 | 확인하지 못함 | 근거 없음. 반영하지 않는다. |

### 2.4 뜨거운 통로 / 찬 통로 격벽

| 확인한 특징 (출처) | 확인 / 추정 | 우리 모델에 이렇게 만든다 |
|---|---|---|
| 격벽은 문과 지붕이 한 세트이고, 뜨거운 쪽이든 찬 쪽이든 만들 수 있다 (S7) | 확인 | 찬 통로에 격벽을 만든다. 우리 방식은 찬 통로 격벽(문 + 지붕). |
| 지붕은 빛이 통하는 폴리카보네이트, 문에는 들여다보는 창 (S7) | 확인 | 지붕과 문 창은 투명에 가까운 반투명 재질(굴절 없이 알파 0.2~0.3). 지붕 높이 200 cm(정해진 값)는 랙 윗면과 같은 높이. |
| 표준 통로 폭 1200 mm. 제품 변형은 600~1100 mm (S7) | 확인 | 찬 통로 120 cm와 맞는다. |
| 랙에 직접 매다는 방식과 바닥에 독립으로 세우는 방식이 있다. 색은 검정과 흰색 (S8) | 확인 | 지붕은 랙 윗면에 얹는 방식. 틀은 어두운 회색 알루미늄 띠. 통로 양끝에 미닫이 문 하나씩. |

### 2.5 공조기(CRAC/CRAH) 외관

| 확인한 특징 (출처) | 확인 / 추정 | 우리 모델에 이렇게 만든다 |
|---|---|---|
| CRAC은 냉매로, CRAH는 냉수로 식힌다 (S11, S12) | 확인 | 우리 홀에서는 이름을 "공조기"로 통일하고, 센서 이름에만 CRAH를 쓴다. 외관은 같다. |

| 통로나 문 앞 표시는 규정이 덜 정해져 있고 필요에 따라 붙인다 (S18) | 확인 | 통로 표시는 작게, 문 앞 사각형 표시만 한다. |

## 3. 정리: 모델에 넣을 특징 10줄 요약

1. 이중 바닥은 60 x 60 cm 타일 격자이고, 천공 타일(급기구 50 x 100 cm = 타일 2장, 열린 면적 약 25% 무늬)은 찬 통로 쪽에만 둔다.
2. 바닥 단면에서 받침대 기둥과 아래 공간이 보이게 하되, 이중 바닥 높이(제안 약 60 cm)는 우리가 정한 값이다.
3. 벽은 밝은 흰색 계열, 천장은 60 x 60 cm 흰색 격자 천장이다. 에폭시 바닥 같은 마감은 근거가 없어 넣지 않는다.
4. 랙은 60 x 100 x 200 cm, 앞문과 뒷문은 천공 강판(열린 면적 약 63%라는 업체 설명 참고), 뒷문은 두 쪽 문이다.
5. 랙 프레임은 어두운 회색 계열(추정), 안쪽 양옆에 세로 케이블 정리 바, 아래에 레벨링 발만 둔다(바퀴 생략).
6. 서버는 1U = 4.445 cm, 폭 48.26 cm, 앞면은 환기 구멍 텍스처(추정)와 1U 이음선만 넣고 로고와 글자는 넣지 않는다.
7. 찬 통로(120 cm)는 문(미닫이)과 반투명 지붕(높이 200 cm)으로 막고, 뜨거운 통로(100 cm)는 열어 둔다.
8. 공조기는 밝은 회색 직육면체(약 1.8 x 0.9 x 2.0 m, 우리가 정한 값), 윗면 회수 격자, 정면 점검 패널 3~4장, 아래로 이중 바닥에 급기한다.
9. 조명은 약 4500 K 중립 백색의 1.2 m 선형 조명을 통로 중심선에 3 m 간격으로 달고, 홀 전체는 밝게 한다.
10. 바닥 표시는 입구와 전기 패널 앞의 노랑-검정 줄무늬 띠와 통로 가장자리 노란 선이며, 글자와 상표는 넣지 않는다.

## 4. 반영하지 않은 것과 확인하지 못한 것

- 특정 사업자나 제품의 색, 로고, 명판 문구, 라벨.
- 확인하지 못함: 서버 앞면 환기 무늬, 프레임 색, 공조기 격자 모양, 벽 마감 일정표, 통로 최소 폭의 표준 조문. 위 표의 "추정" 값은 모델링 담당이 눈으로 보고 바꿔도 된다.
- 표준 원문(ASHRAE, TIA-942, 조명 기준)을 직접 열어 확인하지 않았다. 수치를 공식 값처럼 인용하려면 원문 확인이 먼저다.
