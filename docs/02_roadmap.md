# 02. 로드맵 (약 17주, 단계별 산출물)

- 목적: 단계별 산출물과 완료 기준을 정한다.
- 상태: 채택. 진행 현황은 아래 "진행 현황" 표(2026-10-16)에 적고, 방향 검토는 [17](17_direction_review.md)에 있다.

각 Phase는 **끊어도 결과물이 남도록** 구성한다. 기간은 주당 투입 시간에 따라 조정한다.

| Phase | 기간 | 목표 | 산출물 / 완료 기준 |
|---|---|---|---|
| 0. 작업 환경 설정 | 0.5주 | 저장소, 규칙, 환경 점검 | `check_env.ps1` 통과, `05_env_status.md`, ADR-001~003 |
| 1. USD·Omniverse 기초 | 1.5주 | USD 규격 확정, 검증, 랙 파이프라인, ovrtx 렌더 확인 | 랙 1기 USD(직접 모델링), USD 규격 [09](09_usd_spec.md), 검증 스크립트 v2, ovrtx 렌더 이미지 |
| 2. 모델링 + UE 임포트 | 2.5주 | CRAC·PDU 모델링, 장면 생성(홀 외피는 스크립트가 상자로 생성), 센서 매니페스트, UE 가져오기 | 홀 1개 USD 장면(처음 계획은 랙 20기, 지금은 랙 60기), 센서 매니페스트(처음 80개, 지금 204개), UE 맵, **E1 변환 손실 표**, 결정 D1·D3 |
| 3. 실시간 데이터 | 2주 | 열 시뮬레이션(Warp, 기준선 L0 포함) + 가상 센서 → MQTT → 게이트웨이 → UE | 시나리오 4종, 알람 판정, 녹화·재생, UE 센서 패널 실시간 갱신 |
| 4. 열·기류 볼륨 | 1.5주 | VDB 생성 → UE 볼륨 표시 | 도구 시험과 결정 D2, PoC 영상, 방식 ADR |
| 5. 클라이언트 완성 | 3주 | 알람, 하이라이트, 추이 그래프, 카메라 이동, **내부 둘러보기와 안내 투어, Unreal 고유 기능(나이아가라, 시퀀서, 공간 음향)** | 데모 시나리오 1~4 재현, 데모 영상 |
| 5.5. 외관·환경과 화면 흐름 **(보조)** | 1주(최소) + 1.5주(현실화, 선택) | 최소: 단순 건물과 기본 하늘, 외관 → 층 → 둘러보기 전환, 집계 값 패널. 현실화: 직접 모델링한 외관, 4K 환경 | 첫 화면(외관), 건물 클릭으로 층 진입. 현실화 후 4K 스크린샷과 영상 |
| 6. 스트리밍·배포 | 1주 | PixelStreaming2 + exe 패키징, 혼합 UI | 웹 접속 데모, 웹 패널 1~2개 |
| 7. 비교 실험 | 1.5주 | E2~E4 측정 | 결과표·그래프, 결론 문서 |
| 8. 포폴 정리 | 1주 | 영상, 문서, Notion 반영 | 데모 영상 2분, 아키텍처 다이어그램, README |
| (선택) 9. AI 확장 | 2주 | LLM 알람 요약 / 합성 데이터 | 별도 ADR 후 진행 |

## 핵심과 보조 ([14 핵심 설계](14_sim_to_unreal_core.md))
| 구분 | Phase | 내용 |
|---|---|---|
| **핵심** | 1~5, 6~7 | Omniverse 계열 시뮬레이션, 센서 데이터 Unreal 연동, 표현, 배포와 비교 실험 |
| 보조 | 5.5 | 외관과 환경, 4K 현실화 |
| 보조 | 5의 둘러보기·투어 | 핵심 표현이 동작한 뒤 더한다 |

핵심만 하면 약 14.5주, 보조 포함 약 17주다. 일정이 부족하면 보조부터 줄인다.

## 연구 트랙: Omniverse (Phase와 병행)
[13 Omniverse 연구 계획](13_omniverse_research.md)의 과제 R1~R6을 Phase와 병행해서 진행한다. GitHub Milestone "연구 트랙: Omniverse"로 관리한다.

| 시점 | 과제 |
|---|---|
| Phase 1~2 | R5 열 시뮬레이션 시작, R1 Kit 설치 시험 |
| Phase 3 | R5를 센서 파이프라인에 연결(L1) |
| Phase 4 | R6 부피 데이터 변환, R2 Flow |
| Phase 7 | R4, R3 정리, 결과 요약 |

**일정 참고:** 처음 계획은 약 13~14주였고, 설계 재점검과 요구 추가(Omniverse 기반 시뮬레이션, 내부 둘러보기, 외관 화면)로 약 17주가 되었다. MVP(Phase 0~3)는 그대로 약 6주다.

연구 과제가 막혀도 기준선(L0)으로 Phase가 진행되도록 설계했다.

## 최소 성공선 (MVP)
Phase 0~3 + 5의 일부: **USD 씬 → UE 임포트 → 라이브 센서 → 알람 하이라이트.** 여기까지가 약 6주이며 이것만으로도 포폴 한 페이지가 된다.
